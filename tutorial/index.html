一次 SDK 实验的数据路线

Host 安排工作，device 完成计算。

  1. Python host按 PE 打包输入，并设置有效长度。
  2. H2DHost-to-device：把输入复制到每个 PE 的本地内存。
  3. CSL kernelPE 执行 local scan，接收并向东传递 carry。
  4. 完成 → D2H等待各 PE 完成，再把结果复制回 host。
  5. C++ oracle独立计算参考答案，再逐项核对读回结果。

cslc 是编译器，把 CSL 源码变成可执行的设备程序；SdkRuntime 是 Python 用来加载、传输、启动和回收这次运行的接口。

02

把现象说成人话

局部可以并行，全局仍有先后

A

PE 1 到底在等什么？

它可以提前算自己的 local prefix，但在知道左边四个数合计多少之前，不能把 local 结果叫作 global 结果。

B

怎么知道结果真的对？

检查每个已完成 PE 管辖的位置都等于串行答案，同时它向东发出的 carry 等于到这个 PE 为止的输入总和。

C

如果从 2 个 PE 扩到很多个？

PE 0→PE 1→PE 2→PE 3

local scan 仍能并行；但最东边要等 carry 一站一站走完。PE 越多，这条线性依赖链越可能成为瓶颈。
